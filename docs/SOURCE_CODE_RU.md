# Исходный код и лицензия

Эта сборка создана из исходников в корне данного каталога и распространяется
на условиях LGPL-3.0-or-later. Файл `LICENSE` содержит полный текст лицензии,
а `NOTICE` — сведения об авторстве и происхождении проекта.

Чтобы выполнить требования лицензии при распространении изменённой версии,
передавайте получателю соответствующий исходный код этой же версии, включая
скрипты сборки `install.command` и `build-intel.command`.

Для готовой бинарной сборки соответствующий снимок исходников упакован отдельно
как `Parser2GIS-source-intel.zip` и снабжён контрольной суммой SHA-256.

Исходные проекты:

- https://github.com/interlark/parser-2gis
- https://github.com/Eroloft/parser-2gis-new
