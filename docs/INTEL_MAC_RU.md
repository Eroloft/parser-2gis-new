# Parser2GIS на Intel Mac: простая инструкция

Эта версия предназначена для macOS на процессоре Intel (`x86_64`). Она не
использует ARM-бинарники и не меняет системный Python.

## Что нужно установить

Только Google Chrome: скачайте его с <https://www.google.com/chrome/> и
перетащите в `/Applications`. Установщик проверяет, что Chrome содержит
архитектуру `x86_64`.

## Первый запуск из исходников

1. Откройте папку проекта в Finder.
2. Дважды щёлкните `install.command`.
3. Дождитесь сообщения «Готово». Скрипт:
   - проверит Intel macOS и Chrome;
   - скачает CPython 3.12.15 `x86_64` с проверкой SHA-256;
   - положит Python в локальную `.runtime`;
   - создаст `.venv` и установит зависимости только туда.
4. Дважды щёлкните `start.command`.
5. Если браузер не открылся автоматически, перейдите на
   <http://127.0.0.1:8666/>.

Последующие запуски: только `start.command`.

Не открывайте `parser_2gis/web/static/index.html` напрямую из Finder: адрес
начнётся с `file://`, API будет недоступен. Рабочий адрес панели всегда
`http://127.0.0.1:8666/`, а локальный сервер должен быть запущен через
`start.command` и оставаться открытым в окне Терминала.

В Терминале то же самое выглядит так:

```bash
cd /путь/к/parser-2gis-intel
./install.command
./start.command
```

Для другого порта:

```bash
./start.command --web-port 8766
```

Остановка: кнопка «Остановить» завершает текущий сбор и сохраняет уже полученные
результаты в историю. `Ctrl+C` в окне Терминала полностью останавливает сервер.

## Готовая Intel-сборка

Архив находится в `dist/Parser2GIS-macOS-x86_64.zip`. Распакуйте его и откройте
`Parser2GIS.app`. Сборка имеет проверенную архитектуру Mach-O `x86_64` и
ad-hoc-подпись, но не нотарифицирована Apple. Поэтому при первом открытии macOS
может потребовать: правый щелчок по приложению → «Открыть» → «Открыть».
Глобально отключать Gatekeeper не нужно.

Проверка архива:

```bash
cd dist
shasum -a 256 -c Parser2GIS-macOS-x86_64.zip.sha256
```

Соответствующий исходный код для выполнения требований LGPL находится в
`dist/Parser2GIS-source-intel.zip`; рядом лежит его файл `.sha256`.

Повторная локальная сборка:

```bash
./install.command
./build-intel.command
```

## Использование панели

- Рекомендуется получить собственный ключ официального Places API 2GIS и
  вставить его в одноимённое поле раздела «Параметры». Тогда Chrome для сбора
  не запускается и CAPTCHA веб-сайта не влияет на работу. Ключ существует
  только в памяти текущего запуска и не сохраняется в истории/конфигурации.
  Условия, квоты и доступные поля определяет 2GIS. Контакты доступны только при
  наличии соответствующего разрешения у ключа.
- Вставьте одну или несколько поддерживаемых ссылок 2GIS, по одной на строку:
  результаты поиска (`/search/...`), карточку организации (`/firm/...`) или
  организации в здании (`/inside/...`). Одна страница города, например
  `https://2gis.ru/moscow`, не задаёт направление сбора — для неё используйте
  генератор «Страна → города → рубрика».
- По умолчанию панель русская; казахский доступен переключателем.
- Безопасная пауза между кликами по умолчанию — 750 мс, минимум в веб-панели —
  500 мс. На один запуск допускается до 100 направлений и до 5000 записей с URL.
- Результаты можно фильтровать и скачать в CSV, XLSX, JSON или HTML.
- Кнопки телефона, WhatsApp, соцсетей и сайта открываются вручную. Программа не
  отправляет сообщения автоматически.

История хранится в `~/Library/Application Support/parser-2gis/history`. Она не
удаляется установщиком. Удаление отдельной записи возможно только из панели.

## Ошибки и ограничения

- Сетевые ошибки, недоступные страницы и частично обработанные направления видны
  в журнале; итоговый статус будет «Ошибка» или «Готово частично».
- CAPTCHA не обходится. Если сервис показывает проверку или ограничивает доступ,
  используйте официальный API с собственным ключом либо остановите сбор,
  уменьшите объём и повторите позже в рамках правил сервиса.
- Ошибки ключа и превышение квоты официального API показываются явно. Сам ключ
  не включается в сообщения ошибок и журналы.
- Селекторы и ответы 2GIS могут меняться; реальный сбор требует периодической
  проверки совместимости.
- Локальный сервер слушает только `127.0.0.1`, а не внешнюю сеть.
