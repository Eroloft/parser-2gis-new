# Отчёт о проверке Intel macOS

Дата проверки: 13 октября 2026 года. Среда: macOS 14.8.9, Intel `x86_64`,
Google Chrome universal (`x86_64` + `arm64`), локальный CPython 3.12.15
`x86_64`, PyInstaller 6.22.3.

## Пройдено

1. `install.command`:
   - скачан архив CPython `x86_64`;
   - SHA-256 совпал с закреплённым значением;
   - создана `.venv` на Python 3.12.15;
   - зависимости импортируются.
2. `pytest -v`: **15 passed, 2 skipped**.
   - HTTP-ресурс панели и генератор;
   - запрет посторонних URL;
   - лимит записей и минимальная пауза;
   - фильтры, дедуп и экспорт CSV/XLSX/JSON/HTML.
   - неподдерживаемая страница города отклоняется до запуска Chrome;
   - тайм-аут содержит понятное имя операции и длительность.
   - долгоживущие фоновые запросы не блокируют направление на 120 секунд;
   - CAPTCHA распознаётся и явно останавливает направление без попытки обхода.
   - после первой CAPTCHA остальные направления не запрашиваются.
   - ключ официального API не сериализуется в конфигурацию/историю;
   - выбор API-транспорта не запускает Chrome;
   - поиск, рубрика и карточка организации преобразуются в исходный формат
     `meta/result/items`;
   - сетевая ошибка не раскрывает ключ в пользовательском сообщении.
   - два исходных live-теста 2GIS пропущены как opt-in.
3. Сервер из исходников:
   - `GET /` → HTTP 200;
   - русский интерфейс;
   - `/api/generator` → 18 стран, 204 города, 1785 рубрик;
   - `/api/status` → `idle`.
4. PyInstaller:
   - собраны `dist/Parser2GIS.app` и onedir-вариант;
   - веб-ресурсы, `cities.json` и `rubrics.json` присутствуют внутри bundle;
   - исходная ошибка Python 3.12 (`distutils` отсутствует) исправлена;
   - вызов PyInstaller привязан к интерпретатору `.venv`.
5. Публикуемый архив `Parser2GIS-macOS-x86_64.zip`:
   - SHA-256 успешно проверен;
   - после распаковки `codesign --verify --deep --strict` проходит;
   - главный файл: `Mach-O 64-bit executable x86_64`;
   - `lipo -archs` возвращает только `x86_64`;
   - `Parser2GIS --version` возвращает `2.0.0`.
6. Сервер из собранного бинарника:
   - запущен на `127.0.0.1:8766`;
   - `GET /` → HTTP 200;
   - встроенный русский HTML и API генератора доступны.
7. Подготовлен отдельный архив соответствующего исходного кода
   `Parser2GIS-source-intel.zip`, проверяемый по SHA-256.
8. Повторно проверен сценарий `start.command` после исправления импорта:
   - лаунчер запускает `parser-2gis.py` напрямую через локальный Python x86_64,
     не полагаясь на editable console entry point;
   - сервер запущен на `127.0.0.1:8767`, `GET /` → HTTP 200;
   - регрессионный прогон после исправления импорта: **4 passed, 2 skipped**.
9. Ограниченная проверка текущего 2GIS (один URL, лимит — одна запись):
   - старое 120-секундное ожидание фоновых XHR устранено;
   - обнаружена страница `2GIS Captcha`;
   - задача завершилась со статусом `error` и явным сообщением о CAPTCHA;
   - обход защиты не выполнялся, организации и контакты не создавались.
10. Повторная проверка с тремя направлениями при активной CAPTCHA:
    - выполнена только первая попытка;
    - после обнаружения глобальной блокировки два оставшихся URL не открывались;
    - итоговый статус `error` содержит исходную причину 2GIS.

## Не проверено намеренно

- Полноценный реальный сбор организаций с 2GIS не запускался. Интеграционные
  тесты делают реальный сетевой сбор и запускаются только при явном
  `PARSER2GIS_RUN_LIVE_TESTS=1`. Ограниченный диагностический запрос одной
  записи был выполнен 15 октября 2026 года, но 2GIS вернул страницу CAPTCHA,
  поэтому данные организаций не собирались.
- Реальный запрос к официальному Places API не выполнялся: ключ пользователя в
  среде проверки отсутствует. Транспорт проверен детерминированными mock-тестами;
  доступность контактов дополнительно зависит от разрешений конкретного ключа.
- Не проверены все варианты CAPTCHA, региональных блокировок, лимитов
  аккаунта/сети и будущих изменений DOM/API 2GIS. Программа не пытается их
  обходить.
- Сборка ad-hoc подписана, но не подписана сертификатом Apple Developer ID и не
  нотарифицирована Apple.
- Python 3.13 отдельно не проверялся: готовый сценарий закреплён на 3.12.15.

## Как запустить live-тест вручную

Только если это разрешено условиями сервиса и владельцем сети:

```bash
PARSER2GIS_RUN_LIVE_TESTS=1 .venv/bin/python -m pytest tests/test_parser.py -v
```

Тест ограничен пятью записями на формат, но всё равно обращается к реальному
сервису.
